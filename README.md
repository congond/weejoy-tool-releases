# Weejoy Tool – bản phát hành

**Tải bản mới nhất:** https://github.com/congond/weejoy-tool-releases/releases/latest

Repo này chứa file cài của Weejoy Tool, `latest.json` cho tính năng tự cập nhật trong app.

- macOS chip Apple: `WeejoyTool-macos-aarch64.dmg`
- macOS chip Intel: `WeejoyTool-macos-x86_64.dmg`
- Windows: `weejoy-tool-windows-x86_64.exe`

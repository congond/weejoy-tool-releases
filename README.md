# Weejoy Tool – bản phát hành

Repo này chỉ chứa file cài của Weejoy Tool và `latest.json` cho tính năng tự cập nhật trong app.

Tải bản mới nhất ở trang [Releases](https://github.com/congond/weejoy-tool-releases/releases/latest):

- macOS chip Apple: `*-macos-aarch64.dmg`
- macOS chip Intel: `*-macos-x86_64.dmg`
- Windows: `*-windows-x86_64.exe`
